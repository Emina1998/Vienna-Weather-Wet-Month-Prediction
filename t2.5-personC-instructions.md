## Step 1 — Verify the schema models the raw data in 3NF

Before loading data, add a markdown section explaining why the T2.1 schema is valid.

The schema is:

```text
station 1 ─── N weather_measurement

time_dimension 1 ─── N weather_measurement
```

Explain that:

- station metadata is stored once in `station`
- year/month metadata is stored once in `time_dimension`
- meteorological measurements are stored in `weather_measurement`
- source station and time are referenced using foreign-key-like columns: `station_num` and `time_id`
- there is no repeated station metadata in every measurement row
- there is no repeated year/month metadata in every measurement row
- therefore the schema satisfies 3NF for the purposes of this experiment

Also mention that the raw data columns map naturally into these three tables.

## Step 3 — Clean and transform the raw data

Create the columns required by the DBRepo schema.

### 3.1 Create `station`

The `station` table should contain one row per station number.

Columns:

```text
station_num
nuts_code
district_code
sub_district_code
station_name
latitude_deg
longitude_deg
altitude_m
```

Suggested transformation:

```python
station_df = (
    raw_df[["STAT_NUM", "NUTS", "DISTRICT_CODE", "SUB_DISTRICT_CODE"]]
    .drop_duplicates()
    .rename(columns={
        "STAT_NUM": "station_num",
        "NUTS": "nuts_code",
        "DISTRICT_CODE": "district_code",
        "SUB_DISTRICT_CODE": "sub_district_code",
    })
)

station_df["station_name"] = "Wien - Hohe Warte"
station_df["latitude_deg"] = 48.248611
station_df["longitude_deg"] = 16.356944
station_df["altitude_m"] = 202.0

station_df = station_df.drop_duplicates(subset=["station_num"])
station_df = station_df.set_index("station_num")
station_df.head()
```

Note: the dataset may contain two station numbers (`5901` and `5904`) due to renumbering. Keep both if they occur in the raw data.

---

### 3.2 Create `time_dimension`

The `time_dimension` table should contain one row per year/month.

Use stable `time_id` values in the format `YYYYMM`, e.g. January 2020 = `202001`.

```python
raw_df["ref_month"] = pd.to_datetime(raw_df["REF_DATE"]).dt.month
raw_df["ref_year"] = raw_df["REF_YEAR"].astype(int)
raw_df["time_id"] = raw_df["ref_year"] * 100 + raw_df["ref_month"]

time_df = (
    raw_df[["time_id", "ref_year", "ref_month"]]
    .drop_duplicates()
    .sort_values("time_id")
    .set_index("time_id")
)

time_df.head()
```

If `REF_DATE` is not parsed correctly, inspect the format and adapt the month extraction.
